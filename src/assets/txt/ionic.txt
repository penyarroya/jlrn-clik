INSTALAR IONIC
npm install @ionic/angular@latest

CREAR APP



CREAR UN COMPONENTE
ionic g component features/components/voice-toggle --skip-tests

SINCRONIZAR CAMBIOS CON TU ENTORNO NATIVO ANDROID
ionic cap sync android

EJECUTAR APLICACION
ionic serve

CREAR ENVIRONMENTS
New-Item -ItemType Directory -Force -Path "src/environments"
Set-Content -Path "src/environments/environment.ts" -Value "export const environment = { production: false };"
Set-Content -Path "src/environments/environment.prod.ts" -Value "export const environment = { production: true };"

CREAR SERVICIO
ionic g service services/theme
